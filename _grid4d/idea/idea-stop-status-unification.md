# Stop status unification

> Stop statuses today are chaos - every seat sees a different picture at the same moment. One status truth per story, every seat reading the same state, divergence itself measured.

**Status:** open
**Source:** the Human, 2026-10-31 (consolidation session, [AHA-0017](AHA-0017)) - reported from lived experience

## Idea

At a stop, each seat currently assembles its own status picture - and the pictures disagree. The direction:

- **One truth per story** - the story's state is a single derived view every seat reads, not each seat's local assembly.
- **Every seat reads the same state** - a seat's stop picture names its source; two seats stopped at the same commit see the same story state.
- **Divergence measured** - when two views of the same story can differ, the difference is itself reported, not silently absorbed.

The defect surface lives in the method's CLI today (its stop handler and its status projections); the method picks the fix up. Whatever status surface later graduates to the base arrives already unified.
