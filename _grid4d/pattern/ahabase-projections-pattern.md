# ahabase Projections Pattern

> Declares the generated pages of the ahabase Epic. A page is generated, never written by hand; the generator writes only what is declared here.

**Story:** [AHA-0009](AHA-0009), [AHA-0015](AHA-0015)

## The Epic's own generated content

The package generates these itself - they are not pages of a method's generator:

| Content | Where | Generated by | Checked by |
|---|---|---|---|
| Ontology map - the concepts, grouped by vocabulary facet, with their typed relations | the ontology index, between `<!-- ontology-map:begin -->` and `<!-- ontology-map:end -->` | `ahabase ontology graph` | `ahabase ontology graph --check` |
| Lineage report - concept to implementation blueprint to code, and back through the modules' `Implements:` lines | printed, not stored | `ahabase verify` | its exit code |

## Pages of the method's generator

Declared by [AHA-0015](AHA-0015), after measuring each page's output against this Epic's rule that the open zone names no document of a method:

```yaml
projections: [concepts, issues]
```

- **concepts** (`_grid4d/_generated/epic/AHABASE-Concepts.md`) - this repository's own ontology: the index, every concept with its blueprint column, and the coverage counts. Every link it carries resolves within this repository.
- **issues** (`_grid4d/_generated/epic/AHABASE-Issues.md`) - this repository's own issue documents with their status. Its Related block names three design documents of the method's generator; those names are listed by file and target in [AHA-0015](AHA-0015)'s link check and tied to [open-zone-documents-link-into-the-closed-zone](open-zone-documents-link-into-the-closed-zone) - the rule's standing exception path for generated links.

**Not declared:** `stories`. The sync tail derives an Epic's ticket prefix from its repository name (`AHABASE-`), while this Epic's tickets are `AHA-` - the page would assert `0 completed, 0 open`, a falsehood in the open zone. It joins by name when the generator learns this Epic's own prefix ([story-prefix-derived-from-repo-name](story-prefix-derived-from-repo-name)).

**The fallback rule:** a tree without this declaration file receives the full set from the sync tail - the fallback that produced the 27.10 drift files on the main tree (untracked, since deleted). The declaration merges with its story, so a tree that has the Epic has the declaration and the window stays closed.

A further page is added here by name only after its output has been checked against the rule above.
