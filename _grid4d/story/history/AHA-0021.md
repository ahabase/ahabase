Land the config/instance-state door in the ahabase package - the first real exercise of the graduation seam ([evolucean-ahabase-graduation-run-playbook] Phase 1). ## Seam contract (refined at this story's first review checkpoint, 2026-11-02, both reviewer seats; the refinement and its provenance are recorded below - the flip story quotes this refined text, and the dossier's section 5 carries the same refinement as its 5a amendment)

- **Type:** Python import (library seam), future CLI door `ahabase config` behind the one registry.
- **Surface:** `get_workspace_dir()`, `get_instance_root()`, `get_machine_id()` (workspace-level, no argument, never None) and `load_settings(*, epic)`, `get_data_dir(*, epic)`, `list_scope_holdings(*, epic)` (epic-explicit, required keyword) - re-exported from the `ahabase` package. Implementation sites in the source of the graduation: config.py (load_settings, get_workspace_dir, get_data_dir), config_scopes.py:285 (list_scope_holdings), snapshot_config.py:59 (get_instance_root), claude/claude_config.py:125 (get_machine_id).
- **Settings convention (new, the door's own):** `_config/<epic>-cli-settings.yml` under the workspace; precedence `AHABASE_CONFIG` env (a settings file path, any epic, wins when the file exists) -> the convention path -> missing file is normal and reads `{}`; duplicated keys warn once, last-wins; `wikis_dir`, `workspace_dir`, `config_dir`, `data_dir` get `~` expanded. (Nothing parameterized existed to port - the source hardcodes its own filename; checkpoint 1's correction.)
- **Data layout:** settings `data_dir` when set, else `<workspace>/_data/<epic>`; a relative value anchors at the workspace root; created on demand. (The ported default - the method product's own home directory - could not ride into the open package; on the pilot instance the settings file carries the same path, so nothing moves.)
- **Collab store boundary:** the collaboration store (journal, board, inbox, sessions) stays where the serving epic's data dir puts it - the pilot instance's store does not move; per-epic versus workspace-wide rooting is the collab capability's own landing to decide. (Checkpoint 1's fifth fact, decided here rather than left silent.)
- **Floor:** the first ahabase release carrying them (released tag; the flip pins `ahabase>=X`).
- **Custody boundary:** implementations move; story-scoped config and all per-instance data stay with the instance.
