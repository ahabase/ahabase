# AHA-0027: Direct use of llm from the ahabase door: the door passes its own executable to the bound run and gains session-launch

> Direct use of llm from the ahabase door: the door passes its own executable to the bound run and gains session-launch

**Type:** default
**Epic:** [AHABASE](AHABASE)
**Status:** completed
**Blueprint:** implementation-story-blueprint

## Goal

Serves AHABASE-Priorities rows 1 (safe) and 2 (llm): the Human ruled 2026-11-08 that a migrated capability is called directly from the ahabase door, like `safe` (see EVOLUCEAN-AHB-0009). Measured the same day: with a provider path in the door-visible variants file, `ahabase llm path-list` and `session-env --check` work, but `ahabase llm key` and `path-verify` fail because the door asks the safe in-process, and the safe's bound-consumer check refuses any command line that is not the bound one; and the door has no `session-launch`.

This story makes the door its own caller: `path-verify`, `path-switch`, `session-env` and `key` pass the door's absolute path as the bound helper and as the safe's runner (the library arguments added in AHA-0026), so a `safe://` path works after the owner binds the door once per credential. And it lands `ahabase llm session-launch PATH_ID [CLAUDE_ARGS]...`, the one-command launch the cut table promised. Additive; the released library behaviour is unchanged.

## Requirements

### R1: The door names itself

**Acceptance Criterion:** a test records the keyword arguments the door passes to the library for `path-verify`, `path-switch` and `key`: `executable` and `safe_executable` equal the door's resolved path; the payload helper command of `session-env --out` starts with it and ends with `llm key PATH`, and no planted value is in the file or the output; mutants (verify drops the runner, key drops both, session-env drops the door) go red, reverted.

### R2: session-launch

**Acceptance Criterion:** a test with the launch seam replaced shows `claude --settings FILE` followed by the arguments unchanged, the payload file exists and holds no planted value, an unknown path and a missing `claude` are refused without launching (the missing-claude message names the file); a mutant dropping the arguments goes red, reverted.

### R3: Blueprint and release

**Acceptance Criterion:** the implementation blueprint has the paragraph "The door as its own caller (direct use)" and the frozen seam contract section is byte-unchanged; the full suite and the three-platform matrix are green on the story branch (run id in the Notes).
